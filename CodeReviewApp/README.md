\# Практическая работа №13 — Вариант 12



\## Тема

Автоматизация управления версиями с использованием Git. Code Review Workflow.



\## Что реализовано

\- Создан репозиторий на GitHub

\- Настроен Protected Branch для ветки `main`

\- Реализован Feature Branch Workflow

\- Открыт Pull Request с описанием изменений

\- Проведён Code Review с комментарием

\- Выполнен Merge после проверки



\## Структура проекта

\- `CodeReviewApp/Program.cs` — точка входа

\- `CodeReviewApp/Greeter.cs` — класс с логикой приветствия



\## Ветки

\- `main` — основная защищённая ветка

\- `feature/add-greeting` — feature-ветка с новым функционалом



\## Запуск

dotnet run --project CodeReviewApp
